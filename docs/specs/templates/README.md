# Spec templates

> 用途：为 Spec、Design 和独立 Plan 提供最小但完整的章节骨架。
> 范围：`docs/specs/templates/`。
> 状态：stable。
> 权威语言：中文流程见 [`../README.md`](../README.md)；模板字段使用英文。

| Template | Use when |
|---|---|
| [`feature-spec.md`](feature-spec.md) | 从 intake 到 closeout 在同一篇文档推进 |
| [`design.md`](design.md) | 需要独立设计与架构评审 |
| [`plan.md`](plan.md) | 需要可交给第三人逐项执行的独立实施计划 |

模板只定义必答维度，不复制具体项目规则。不得删除风险扫描、迁移/发布、逐任务验证或回滚字段；不适用时写明 `N/A` 及理由。
